# I18n (translate / locale / files)

Use when the user asks to add, change, or verify **translations, locales, or i18n behavior**.

## 1. Core API and helper

- **Interface:** `Switon\Core\TranslatorInterface::translate()`
- **Default implementation:** `Switon\I18n\Translator`
- **Helper:** `t(string $id, array $bind = [], bool $useICU = false): string` — `$id` e.g. `user.not_found`; `$bind` for
  `{key}`; `$useICU` → ICU MessageFormat vs simple replacement.

## 2. Placeholders

- **Simple mode (`useICU = false`):** Placeholders `{key}`; non-string in `$bind` JSON-encoded before replacement.
- **ICU mode (`useICU = true`):** Requires `intl`; else `Switon\I18n\Exception\IntlExtensionRequiredException`. Uses PHP
  `\MessageFormatter` (current
  locale) for plural, select, date/number. Non-scalar in `$bind` → JSON-encoded; scalar and `DateTimeInterface` as-is.
  On format failure → raw template returned. Do not mix `{key}` and ICU syntax in one message; use separate keys.
- **ICU syntax (where to look):** Plural: `{count, plural, one {# item} other {# items}}`. Select:
  `{gender, select, male {he} female {she} other {they}}`. Date/number: `{when, date, short}`, `{n, number}`. Full
  syntax: PHP [MessageFormatter](https://www.php.net/MessageFormatter),
  ICU [Unicode TR35 (MessageFormat)](https://unicode.org/reports/tr35/tr35-messageformat.html).

## 3. Locales

- **Locale:** `Switon\Core\LocaleInterface` — `get()` / `set()` / `getDefault()`. `get()` returns default when
  no request-local set. Config: see implementation (e.g. `Switon\I18n\Locale`).
- **From HTTP (switon/http):** `Switon\Http\Filter\RequestLocaleFilter` — order: query → cookie →
  Accept-Language; query param typically `lang` (configurable); does not write locale back to cookie. Config: see that
  class.

## 4. Fallback

- **Candidate order** (e.g. for `zh-CN`): exact locale → language-only (`zh`) → default locale from `LocaleInterface`.
- **Loading files:** Try each candidate’s locale file (lazy on first `translate()` per locale); if none exists →
  `Switon\I18n\Exception\LocaleFileNotFoundException`.
- **Key lookup:** Key resolved in candidate order; first hit wins. Missing in all → key used as template, dispatch
  `Switon\I18n\Event\TranslationKeyMissing` (§6).

## 5. Translation files

- **Directory:** Default `@resources/i18n`. Only flat `*.php` in that directory (no subdirectories). Config: see
  `Switon\I18n\Translator`.
- **Naming:** One `*.php` per locale; filename = locale lowercased (e.g. `en.php`, `zh-cn.php`).
- **Shape:** File returns `array<string,string>` (flat keys only; no nested array structure). No file cache — changes on
  disk visible on next request.

```php
<?php

return [
    'user.not_found' => 'User not found.',
    'user.welcome' => 'Welcome, {name}',
];
```

## 6. Missing keys and monitoring

- Key missing in all candidates → key used as template; replacement still runs. Dispatches
  `Switon\I18n\Event\TranslationKeyMissing` (event carries `key` and `locale`; log:
  `switon.i18n.translation.key.missing`).

## 7. Where to use i18n

- **Templates:** `t()` (see [view.md](references/view.md)); output via `{{ t(...) }}` — template engine escapes by
  default; `t()` does not escape.
- **Classes:** Prefer `TranslatorInterface::translate()`; `t()` allowed. No locale parameter on `translate()` — set
  locale before each call to render in another locale. `has(key)` is available when you need an existence check.
- **Package:** Composer `switon/i18n` provides `Switon\Core\TranslatorInterface` and `Switon\I18n\Translator`.
