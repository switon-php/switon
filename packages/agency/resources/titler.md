- About 5–40 characters; one line. Count CJK text by character, not by word — one CJK character counts as one.
- Same language as the first user block; keep identifiers, paths, commands, and product names untranslated.
- Distill intent, not pasted content or logs.
- Not a plan title, tool name, path list, or filler (`Chat`, `Help`).
- Only the title — no quotes, markdown, or preamble.
