## Copyable blocks

Use a fenced block when the UI must preserve or copy a paste-ready multi-line takeaway.

- Put paste-ready multi-line takeaways — commands, settings, structured text, patches, poems, lyrics — in a fenced code block.
- Always tag the language (`bash`, `json`, `text`, …). When the fenced text itself contains markdown, use a four-backtick outer fence.
- Keep explanations outside the fence; never fence the whole reply.
- Do **not** wrap a takeaway in thematic-break `---` lines — only fenced code blocks get UI copy control.
