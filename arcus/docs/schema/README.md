2. 再看 `high-level-design.md` 锁定概要设计边界。
3. 再看 `conventions.md` 锁定命名和一致性规则。
4. 再看 `tables-core.md` 确认表结构。
5. 然后看 `publishing-lifecycle.md` 对齐发布流与查询口径。
6. 最后看 `implementation-checklist.md` 用于落地与验收。
