# Proof Routing

Map assertions to the narrowest reliable proof:

- fenced PHP snippets → shared snippet validator
- Markdown links and anchors → link audit
- locale anchor inheritance → locale anchor parity
- symbols and machine-meaningful identifiers → source-backed identifier review
- shared beginner path (`tutorial`, `guides`, `getting-started`) → controlled learning-mainline proof app checks

Prefer layered proof:

1. cheap automated proof first
2. stronger runnable proof second
3. manual source-backed review only where automation is still insufficient
