# Assertion Types

Use these categories when treating docs as proof-bearing assertions:

- `symbol assertions`
  - classes, methods, attributes, config keys, command names
- `behavior assertions`
  - defaults, flow order, ownership boundaries, output shape
- `learning-path assertions`
  - chapter checkpoints, command sequences, hidden prerequisites
- `doc-integrity assertions`
  - links, anchors, cross-page continuity

One doc page may contain several assertion types.
Do not force every claim through one validator.
