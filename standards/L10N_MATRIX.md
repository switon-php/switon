# Switon Global L10N Matrix (The "Ubiquity" Strategy)

## 准入基准 (Criteria)
1. **Google SEO 有效性**：Google 搜索引擎与翻译原生支持（确保有充足的网民基数和搜索索引价值）。
2. **AI 质量兜底**：大语言模型（AI）具备该语种的中高级语法能力，结合 `SKILL.md` 的“混合翻译（Code-switching）”规则，可实现**零人工 Review** 的高质量技术文档输出。

## 🔴 第三阵列：剔除黑名单（满足 Google 但 AI 不建议做）
*特征：虽然 Google 搜得到，但由于语料过于稀碎、方言破碎、或 AI 生成技术上下文极易“严重幻觉”，为了不砸招牌，坚决放弃。*

| 语种名称 | 代码 | 剔除原因 (AI 质量无法兜底) |
| :--- | :--- | :--- |
| **库尔德语** | `ku` | 存在 Kurmanji 和 Sorani 等严重方言分裂，且使用不同字母表，极易生成乱码。 |
| **科西嘉语 / 弗里斯兰语** | `co, fy` | 语料极度匮乏，AI 在组合技术词汇时会出现严重的“语法断裂”，连白话都串不通。 |
| **萨摩亚语 / 毛利语** | `sm, mi` | 纯属文化保留语种，完全没有外包土壤，且 AI 幻觉率超过 40%。 |
| **塔塔尔语 / 维吾尔语** | `tt, ug` | 涉及部分敏感 Token 或双向文字处理极度不稳定，直接规避。 |
| **世界语 / 拉丁语** | `eo, la` | 人造/古典语言，没有真实的商业与接单环境，纯噱头，浪费算力。 |
| **卢森堡语 / 意第绪语** | `lb, yi` | 卢森堡人全用德/法语接单，意第绪语全用英语/希伯来语，没有排版性价比。 |
