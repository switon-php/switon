# Guides {#guides}

Use these task-first guides when the job is already clear and you want the shortest path to a working result.

## Start here {#start-here}

If you do not have a local runtime ready yet, start with [Install Switon](../getting-started/install.md#install) or [Environment setup](../getting-started/environment.md#environment).

Use guides when the task is already clear.
If you are still learning the normal Switon build order, start with the [Tutorial](../tutorial/README.md#tutorial) instead.
Use component `README.md` files for the authoritative package contract.
If you are not sure where to start:

- [Build an API](build-an-api.md#build-an-api) when you want the shortest task-first start
- [Tutorial](../tutorial/README.md#tutorial) when you want the slower ordered path
- [Core concepts](../concepts/README.md#switon-fundamentals) when you want the framework methodology and mental model first

Do not read the whole index first.
Pick one task and start there.
