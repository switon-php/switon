# Switon Docs (English) {#docs}

This directory is the English documentation source for Switon.

For the website homepage, open [index.md](index.md).
For the published docs experience, start from the site home rather than this repository view.

This page is only a repo-facing pointer map. Use one route below, then leave this page.

## What this directory contains {#scope}

- `index.md` — website homepage for the English docs
- `getting-started/README.md` — local setup, install, and first proof
- `concepts/README.md` — framework methodology, boundaries, and placement decisions
- `guides/README.md` — task-first routes such as building an API or adding queue-backed work
- `tutorial/README.md` — one ordered beginner path
- `terms.md` — internal terminology baseline for localized docs writers
- package directories such as `http/README.md`, `di/README.md`, `context/README.md`, and `orm/README.md` — owner docs for specific framework boundaries

## Start here {#start-here}

- **To see the actual website homepage source:** [index.md](index.md)
- **To begin the normal first-user path:** [Getting started](getting-started/README.md#getting-started)
- **To understand what `Switon` is trying to standardize:** [Concepts](concepts/README.md#switon-fundamentals)
- **To compare the differentiating framework patterns:** [Highlights](highlights/README.md#switon-highlights)
- **To browse package docs directly:** [Packages](packages.md#packages)

## Read by intent {#read-by-intent}

- **I want local setup and first proof** — [Getting started](getting-started/README.md#getting-started)
- **I want one concrete task path** — [Guides](guides/README.md#guides)
- **I want one slower learning route** — [Tutorial](tutorial/README.md#tutorial)
- **I want the framework model first** — [Concepts](concepts/README.md#switon-fundamentals)
- **I already know the boundary I need** — [Packages](packages.md#packages)

If you are unsure, use this order:

1. Start with [Getting started](getting-started/README.md#getting-started)
2. Continue to [Tutorial](tutorial/README.md#tutorial) if you still want one ordered learning path
3. Switch to [Guides](guides/README.md#guides) only when the next app task is already clear
4. Use [Packages](packages.md#packages) only after you already know which boundary you need
