# Switon mark — structure rules

Switon mark is not an outer shell with an inner symbol.
It must be one unified construction system.

## Core definition

- Build the whole mark from one consistent matchstick / block-like geometric language.
- The whole mark should read first as a diamond-shaped `8`.
- The overall motion should suggest an `S`.
- The middle mirrored turns should suggest a `W`.

## Hard rules

- Use one construction language across the whole mark.
- Keep visual stroke weight consistent across all major parts.
- Keep angle logic consistent: diamond-like or chamfered turns only.
- Do not mix shell language and inner-symbol language.
- Do not add loose nodes, small decorative diamonds, interface blocks, or floating pieces.
- The center spine is only a structural organizer, not a separate inserted object.

## Allowed parts

Only these three structural regions should exist:

1. upper loop / upper diamond unit
2. lower loop / lower diamond unit
3. middle mirrored connection that creates the `W` reading

## Reading order

1. a stable framework-like symbol
2. a geometric matchstick `8`
3. a subtle `S` flow across the full contour
4. mirrored `W` turns in the middle connection

## Anti-patterns

- outer shell + unrelated inner icon
- center pole inserted into a separate frame
- extra terminal blocks or circuitry clutter
- explicit letter drawing instead of structural emergence
