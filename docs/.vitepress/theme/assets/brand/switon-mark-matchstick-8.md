# Switon mark — matchstick 8 direction

Core idea:

- Start from a geometric matchstick `8`, not from explicit letters.
- Let the whole contour read as a stable, symmetric `8`.
- Let the middle side turns imply mirrored `W` shapes.
- Let the overall flow suggest an `S`, but only as a secondary reading.

Constraints:

- Keep the mark vertically symmetric.
- Keep the construction minimal: one outer shell, one center spine, two mirrored side turns.
- Avoid extra nodes, loose interface blocks, or decorative pieces.
- Prefer diamond-like corners and straight segments over soft rounded app-icon language.

Reading order:

1. A clean framework-like symbol
2. A matchstick `8`
3. Mirrored `W` side turns
4. A subtle `S` flow across the whole mark
