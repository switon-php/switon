# RBAC Area

The RBAC area manages roles, permissions, and role assignments.

## Scope

- Role definition and lifecycle
- Permission catalog and assignment
- Subject-role mapping

## Related Areas

- Admin area for login, workbench, and message-center operator flows
- Org area for structural context
- Menu area for permission-bound navigation
- File area for reusable admin avatars
