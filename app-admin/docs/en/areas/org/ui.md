# Org UI Surfaces

This page describes the default UI surfaces for organization management.

## Default Pages

- Department management
- Position management
- Group management
- Staff assignment management

## Usability Defaults

- Keep department as required in staff onboarding.
- Keep position and group optional in basic mode.
- Use progressive disclosure for advanced fields.

## List View Recommendations

- Default columns should stay short and operational.
- Optional columns should be toggleable in table settings.
- Keep filter panels scenario-oriented (department-first for most admin views).

## Detail View Recommendations

- Show primary department and primary position first.
- Put additional positions and groups in collapsible sections.
- Keep relation editing close to the staff profile page to reduce navigation cost.
